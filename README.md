# Wings design assets

Agreed mockups for the wings redesign, referenced from [#95](https://github.com/sergnio/sergn.io/issues/95) and [#96](https://github.com/sergnio/sergn.io/issues/96). Not part of the site.

- `wings/main-list/a-evolved.html`: the main list. Older versions are the `vN.html` files.
- `wings/wing-page/wing-combined.html`: the wing page. `final-placeholder.html` and `placeholder-spec.md` define the "No photo yet" placeholder.
- `wings/screenshots/`: each design at 1280px and 390px.

Open an HTML file locally to view it. Add `?screen=list` to the main list.
